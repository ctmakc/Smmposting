# Evergreen Article Import Pack

This folder contains external-blog article drafts generated from the INNOVA AI section packs.

Purpose:
- keep rewritten article-style drafts close to the posting engine
- make later Medium / vc.ru / Teletype ingestion straightforward
- preserve source linkage back to the service-page content packs

Structure:
- `manifest.json` — machine-readable list of all drafts
- `<brand>/...md` — per-article markdown files with frontmatter
